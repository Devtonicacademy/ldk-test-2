# Lakeduck Integrated Limited

A modern corporate website for **Lakeduck Integrated Limited**, showcasing the company's agricultural commodity trading, export services, and recycling solutions.

## Features

- Responsive design
- Company profile
- Agricultural commodities
- Recycling solutions
- Projects & sustainability
- Contact & inquiry forms
- WhatsApp integration
- SEO optimized

- Shea Butter

## Services

- Agricultural Commodity Export
- Plastic Recycling
- Tire Recycling
- Waste Management
- Environmental Solutions
